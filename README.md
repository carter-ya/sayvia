# Sayvia

面向 GitHub 等网站的 AI 翻译 Chrome 扩展，帮助用户阅读其他语言的内容，并在原有编辑框内完成跨语言表达。

## 当前状态

项目处于技术验证准备阶段，尚未发布可安装扩展。首版优先适配 GitHub；Product Hunt 评论框专项适配安排在后续阶段。

## 产品方向

- 阅读选中文字，保留代码等必要语义信息。
- 编辑框译文预览、修改、复制、替换及恢复原文。
- 支持 OpenAI、DeepSeek 与兼容接口。
- API Key 在本机永久保存，正常重启与更新保留。
- 草稿变化时阻止旧译文覆盖，由用户自行提交评论。

上述是产品规划，实际能力以各阶段验收及发布说明为准。
