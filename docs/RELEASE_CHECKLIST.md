# Sayvia 0.1.0 发布前检查

这是检查单，不是发布批准。正式发布前须补齐本单，不把已构建、PR 合并、模拟回包或 AI 初筛视为真人验收。

## 自动证据

- [x] 设置、网站选区图标直达、手动翻译、写作预览／快速替换均有实际扩展回归。
- [x] 模型协议与格式计划真实调用：Luna／Flash 各 30 条，结构和保护 30/30，见 [模型报告](validation/release-model-results/README.md)。
- [x] 现有样例与所有新质量判定保持真人待评，不自动生成通过结论。
- [x] 当前 Chrome 稳定版及前一个主版本的隔离自动回归，见 [S12b](validation/S12b.md)。
- [ ] 所有层的最新 head 均完成 Codex 审核，无有效未解决问题，CI 成功并逐层合并。
- [x] 补齐 GitHub 评论框入口与单次源语言，开发预览包与其源提交一致且同包冒烟通过，见 [S12b](validation/S12b.md)。
- [ ] 最终生产 ZIP、校验值及源提交一致，安装验证对应同一版本。

## 人工验收（用户已允许移至发布前）

- [ ] 逐条评审两个模型的 30 条结果，各自至少 27 条可直接或轻微修改后使用，无严重语义错误。
- [ ] 质量验证包含简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语及显式源语言；现有主报告目标语言为中英，不代表八语言已完成人工评审。
- [ ] 在真实 GitHub 专用测试内容中，由测试者手动提交替换后的评论；核对正文与载荷，不由扩展或代理代为提交。
- [x] macOS 实际工具栏 popup 的草稿保留、键盘发起后关闭重开显示真实 Luna 译文；同 ID 重新加载后原 Key 无需输入即可使用。
- [ ] 原生工具栏 popup 的点击外部关闭／立即重开、中文输入法组合和取消的完整细节；既有 Esc 关闭和隔离浏览器测试不替代这些项目。
- [x] 解锁后的 macOS 原生选区图标、右键与 ⌘⇧Y 当前选区翻译，无选区／受限页反馈；临时 Docs 主机授权已撤销。
- [ ] 原生快捷键冲突提示的完整验证。
- [ ] 普通桌面条件下的交互反馈验收；已有 headless 观测和原生路径证据见 S12b。
- [ ] 真实设备重启后保留模型配置和仍有效的 Key；正常升级后确认同 ID 保留。
- [ ] GitHub Discussions 给出实站结论；未验证时保持不启用专项回写。Product Hunt 评论框仍属于 P1。

## 交付边界

- [ ] 正式上架前使用开发者信息中心的公钥核对商店 ID；当前固定 key 仅用于开发解压包，首次变更身份需明确配置迁移边界。

- [ ] 使用与 [隐私说明](../PRIVACY.md) 一致，不承诺 Key 加密或服务商侧删除。
- [ ] 检查扩展安装包没有 Key、环境文件、评估凭证、测试入口、个人浏览器会话和远程脚本。
- [ ] 由用户确定上架商店、许可证及收费策略；本项目不代为作出这些决定。

未上架商店、未选择许可证或收费方式不妨碍本地预览，但不能据此承诺商店已发布、采用某个开源许可或收费已获授权。
