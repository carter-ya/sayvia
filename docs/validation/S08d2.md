# S08d2 正式弹窗与手动翻译

日期：2026-11-01。直接依赖 S08d1。

弹窗分为当前页面与手动翻译，支持键盘页签切换。概览显示捕获的目标标签页、网站选区入口状态、默认模型和阅读／写作目标语言。网站读取备用入口复用现有精确文档注入，受限页面明确引导手动粘贴。

手动页提供模型、目标语言、原文、可编辑译文、取消与复制，输入和结果在一屏内可用。已保存草稿／运行中任务在重开时继续显示；输入即保存，不依赖 debounce 或卸载回调。弹窗关闭只停止界面轮询，后台请求继续；再打开只读现有状态，不重发请求。超出 12,000 字符时保留当前显示并提示超出部分未保存，禁止请求。API 授权只来自可信按钮点击，使用已保存模型地址；网站替换不由手动页触发。

已有扩展浏览器测试验证未提交输入与编辑候选立即关闭后重开、关闭后后台完成、取消中断实际 fetch、不同标签页隔离和其他窗口清除数据。配置、草稿、会话代际均由后台受限接口提供；清理后仍绑定初始标签页，不因设置页成为活动标签而误改任务归属。

已用自制服务与实际扩展构建检查明暗主题截图。所有新场景为模拟模型，不能代替真实译文质量；原生工具栏 popup 的焦点和关闭行为仍须在 Mac 解锁后验证。

PR #19 复现并修复启动回复延迟时取消仍指向空／旧任务的问题：在等待草稿保存前记录新任务标识，取消始终使用本次标识；若尚未派发则跳过启动，取消后的迟到启动回复不能重写界面。表单等待启动收尾后解锁，旧代际收尾不解除新任务的锁。新增实际扩展场景覆盖首次翻译和恢复草稿；前两项先在旧代码上确认请求没有被中止，再验证修复。以上只延迟本地消息回复，模型使用隔离自制服务。
