# S10 写作预览与快速替换

日期：2026-11-01。直接依赖 S08d2。

正式偏好提供默认关闭的快速替换。页面打开时先确认已保存偏好，确认前翻译按钮保持不可用；任务开始时记录是否提前开启快速替换。结果到达时后台再次检查当前开关，用户在等待中关闭后不自动写入。仅当前原编辑框、有效快照、未变修订、完整校验与后台 canApply 均允许时复用同一 TextEditorSession.apply 路径；后台恢复、原稿变动或校验失败不自动覆盖。手动粘贴与阅读不参与快速替换。

写作面板显示本次全文／选区及替换模式，保留译文编辑、复制、手动替换、恢复、冲突后复制原文。未获验证的编辑框明确引导工具栏手动粘贴，不展示无法实际使用的“复制”降级指引。扩展不提交网站内容。

新增扩展回归覆盖用户开启后自动替换且可恢复、输入修改再撤回仍不覆盖、等待中关闭开关只预览，以及通用 text input 只替换记录选区并触发网站 input 状态。既有 core-workflow 回归覆盖默认预览、Markdown 保护、输入法与草稿失效、恢复冲突、不支持编辑框和未应用译文确认。

兼容范围：GitHub Issue／PR 常规 Markdown textarea 使用专项适配；通用普通 textarea／text／search input 使用运行时检查。GitHub Discussions 仍未完成实站验证，不启用专项回写；富文本、密码、只读控件与跨域 iframe 不承诺直接回写，使用手动粘贴。Product Hunt 评论框属于 P1，MVP 仅获授权页面的阅读选区。

本层测试使用自制模型服务，非真实质量证明。真实 GitHub 手动提交、Discussions 实站结论、真实 OS 入口和发布质量的剩余检查在 S11／S12 及人工发布前完成。不能以快速替换模拟通过宣告最终可发布。
