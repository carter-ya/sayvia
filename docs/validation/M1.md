## 真实 GitHub 验证步骤

测试者选择允许发布测试内容的专用 Issue／PR 评论框；扩展不自动创建或提交评论。

1. 在设置中保存模型与 Key，点击授权 API 主机；回到实际 GitHub 测试页，从工具栏打开写作翻译。
2. 准备带代码、链接和否定条件的公开测试草稿，选择其中一段；核对原文预览及目标语言后翻译。
3. 修改候选措辞、执行替换，检查原选区外文字未变。由测试者手动提交，核对 GitHub 实际收到的新正文。
4. 对另一份测试草稿执行替换后恢复，核对完整原文；再做一次“用户修改后尝试恢复”，确认不会覆盖新输入。
5. 请求期间编辑原稿、页面刷新或导航，确认旧结果无法覆盖；阅读模式选取含 code 的文字，确认代码保留且网页没有被重写。
6. 记录浏览器版本、扩展源码版本、服务／模型、输入来源和结果。Discussions 独立记录兼容性，当前不声称拥有其已验证的写入适配。
