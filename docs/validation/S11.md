## 本层变化与实际命令

新增跨模块场景验证写作／手动任务共用标签页互斥、手动请求期间清除配置、竞争弹窗保留未保存文字、真实剪贴板粘贴与恢复冲突原文复制。先用失败测试复现“阅读关闭跳回旧写作框”，再修复为恢复本次阅读前的焦点。快速替换补测格式无效与限流，均不写原稿、不重试，也不显示上游私有错误。

初次完整 `pnpm check` 为 309 项单元、71 项浏览器通过。后续新增焦点／剪贴板、失败保护、键盘场景，并纳入 PR #17 的旧选区修复后，重新运行 typecheck、lint、format:check 与 `pnpm test`（309 项单元），以及两个官方 Chrome 版本的全部 77 项浏览器，均通过。最后完整官方回归对应已合入上游修复的代码，不拼接旧版本测试结论。

使用官方 Chrome for Testing，mac-arm64、headless、隔离配置文件；没有使用用户登录、真实 Key 或私有页面。命令形式：

```sh
pnpm typecheck

pnpm test
SAYVIA_CHROME_PATH=/path/to/official/chrome pnpm exec playwright test --output /tmp/sayvia-version-results
```
