# READ01 网页原位译文与文末快捷横栏

日期：2026-11-03。按本次会话确认的紧凑快捷横栏实现，沿用 UX09 外观。此记录针对工作区实现，不表示已提交、通过远端审核或发布。

## 行为与边界

- 阅读结果完整校验后，提供“在网页中显示”；用户点击后才修改当前页面文字并关闭浮窗。服务端正文与写作编辑器状态不受此操作影响。
- 普通正文、跨段落及包含链接／行内代码的明确映射可原位显示。仅写入原有 Text 节点，保留选区外文字、链接元素／目标、代码及原有网站事件。连续同父文本节点允许合并映射，不按译文字数分配节点。
- 源 Markdown 与原 DOM 的可见文本叶子逐一核对；结果复查相同结构、链接和代码。复杂样式产生歧义、源码 diff、全代码选区、交互控件及富文本编辑器保留预览与复制，不猜测映射。
- 文末仅保留“译文／原文 ···”；点击后以文档级 Shadow DOM 浮层显示原文切换、复制、查看。按钮使用无强调底色的中性小图标与文字，悬停轻微高亮；共享清蓝／珊瑚、主题、材质及背景染色设置。
- 切换复用当前结果，不调用模型；查看重新打开当前译文。重新选择已翻译区域会复用已有记录，重新翻译使用原始来源文本。修改译文后仍须通过结构校验才能原位显示。
- 快照观察选中节点、父节点及祖先变化；文字改动后改回、节点重建、链接属性变更和导航均使旧快照失效。失效后不使用旧原文覆盖网站新内容。扩展自己的 Text 写入和独立入口不当作网站修改。
- 页面最多保留 20 处记录；超限淘汰最早记录，快照仍有效时恢复其原文。会话销毁和访问停用也仅恢复仍有效的快照；刷新后不持久化原文／译文记录。
- 长度变化后，文末入口跟随最后一个所选文本节点所在的文本／链接／代码片段末尾；局部选区不会为了插入入口而拆分原有文本节点。浮层与正文分离，避免被正文容器裁切；滚动和窄屏时限制在视口内。

## 验证

新增 10 项单元覆盖部分选区、相邻文本节点身份、反复切换、元素身份和网站监听、链接／代码保护、无效结构原子拒绝、修改再撤回、重建、属性变更、扩展入口和结束恢复。

新增 6 项真实扩展浏览器场景覆盖预览后原位显示、紧凑横栏、脚本点击拒绝、复制、查看、反复切换且请求数不增加、多处记录、选区外文字、动态更新、复杂结构回退、已有记录复用、重新翻译的原文来源、UX09 外观同步和访问撤销清理。验证使用隔离 Chrome、虚拟 Key 与本机模拟模型，不读取用户凭证，不调用付费模型。

首轮浏览器回归发现：正文断言需读取原 DOM 的 textContent，以免将 Shadow DOM 内文末按钮文字算作正文；关闭浮窗后的隐藏焦点也会吞掉下一次键盘选区事件。分别修正断言与真实焦点清理后，连续翻译流程通过。外观测试使用标签的实际可访问名称，避免把 select 的所有选项文本当作精确标签名。

隔离前的共享工作区完整 `pnpm check` 曾通过类型、lint、格式、生产构建、526 项单元及 158 项浏览器测试（浏览器部分 4.9 分钟）；其中包含其他任务的 diff 修复与文档类型引导，不作为本 PR 独立提交的通过证据。本 PR 从 main 的 c5773e8 基线隔离，只保留 READ01，独立检查结果在 PR 描述及对应最新提交的 CI 中记录。原工作区的其他改动没有被移除或覆盖。已查看真实扩展生成的文末横栏截图；这是隔离浏览器证据，不替代真实网站的最终人工兼容性验收。
