# S07 最小阅读与写作闭环

日期：2026-10-31。基于已合并 S06a/S06b（PR #8、#9）。

## 实现范围

工具栏弹窗提供网页选区与当前输入的入口；只在明确操作时通过 activeTab/scripting 注入主 frame，并把打开命令定位到 executeScript 返回的原 documentId。重复注入复用同一文档控制器；内容脚本不接受网页 postMessage 或不可信点击来启动付费请求或替换。

最小面板使用隔离样式，显示原文、目标语言、实际模型及可编辑译文，支持重新读取、翻译、取消、复制、选区／全文替换与一步恢复。所有结果以文本呈现，不执行模型 HTML。关闭与 Escape 对未应用的译文编辑确认，复制失败保留可手动选择的内容。

请求使用已预览的冻结快照，不在点击翻译时悄悄重读后来变化的原生选区。原稿变化要求明确重新读取；模型执行中的输入变化不可恢复替换资格。替换前检查来源、原节点、修订、全文、原始范围及完整候选格式；后台恢复后的结果只可预览／复制。完整候选编辑沿用区间保护与 AST 结构校验，保护 URL、代码、HTML、引用与原有空白结构；普通措辞可修改，无法证明有效时降级复制。

设置中可在用户点击时申请当前 API 主机的可选权限，保存 Key 与授权相互独立。API 授权不自动为该主机注入页面脚本。永久保存与迁移沿用 S02；本层不增加默认网站权限或调试通道。

## 真实扩展评估工具

先构建，再以本机环境文件运行。Key 不放进命令参数、PR、日志或报告；须关闭 DEBUG/PWDEBUG。工具只用自制公开样例，每款三次，拒绝覆盖报告，要求源码已提交，结果持续追加至权限为 0600 的 JSONL。临时浏览器配置在退出时删除。正式运行不会成为 CI 的自动步骤。

```sh
pnpm build
env -u DEBUG -u PWDEBUG pnpm exec tsx --env-file=.env.local scripts/evaluate-extension.ts --output evaluation-results/s07-ui.jsonl
```

使用 worktree 时传入主仓库环境文件的实际绝对路径。可通过 SAYVIA_CHROME_PATH 指定独立的测试浏览器，不使用日常 Chrome 配置。测试副本只额外授予固定 API 与公开本机／模拟 GitHub 页面主机权限，发布包不携带这些静态主机授权。

## 持续验收：重复打开与目标切换

在已合并版本 76ed11c 上增加实际浏览器检查后，确认重复点击工具栏会重新执行 WXT bundle，旧上下文先被销毁，编辑后的候选译文变为空串，未出现放弃修改确认。原先“面板数量为一”的检查没有覆盖数据保留，不能证明复用成功。

修复后先以无副作用脚本取得浏览器确认的主 frame documentId，再探测该文档的现有控制器。只有不存在有效接收者时才向同一 documentId 注入 bundle；随后仍按精确文档发送打开命令。已有控制器保留候选与编辑器会话，用户拒绝放弃时不会产生新模型请求，候选仍可替换原稿。页面已导航时不把注入改投新文档。

复用控制器后，补齐编辑目标切换：焦点进入富文本、密码或只读框时清除上一编辑器的候选目标，不能回退到上一份草稿；回到新的受支持文本框后可正常重新预览。该问题在新复用路径下先复现再修复，旧版本的重建行为曾掩盖它。

局部验证：7 项页面路由单元测试、13 项完整核心流程浏览器测试通过。新增实际浏览器场景覆盖三个不支持的目标，以及重复打开后拒绝丢弃、保留候选、最终替换和不增加模型调用。算法、服务预设及系统提示词没有改变；本次未重复付费模型调用。完整检查结果以对应 PR 的 CI 为准，M1 人工验收状态不变。
