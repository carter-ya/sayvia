# S06a Offscreen 执行器与真实 Worker

日期：2026-10-31。对应 PR stack S06a；直接基于已合并 S05。

## 行为与边界

本层提供 Offscreen 内部执行器，最多并行四个任务。相同 taskId 重复 START 返回既有状态，不再次请求；CANCEL 可以先到，取消墓碑阻止其后的 START。执行预算从接纳起计，最长 60 秒，覆盖 Worker 解析、请求和结果校验；取消／到期终止 Worker 并中止请求，迟到结果不能覆盖终态。

Worker 执行真实的 SourceInput 校验、TranslationPlan、模型 payload 与重建。API Key 及网络请求留在 Offscreen。沿用 S05 的提示词、请求参数及格式算法；没有付费模型调用。本层没有用户入口，网页无法直接提交内部执行命令；后台任务代理、主机授权与路由在 S06b 接入。

Offscreen 主动创建内部 runtime Port；开始命令通过后台持有的接收端 Port 返回，避免将 Key 广播至扩展界面。内部命令严格校验 protocolVersion、requestId、随机 epoch/token 与白名单字段；既有执行环境不能被新 token 重绑定。重连请求只接受本扩展 background.js，结果通知仅携带任务编号。此层新增 offscreen 权限，没有默认网站注入或默认主机权限。

完成结果仅在 Offscreen 内存保存 30 秒；确认交付后立即清除。终态去重记录最多保存五分钟，任务表最多 512 条，达到上限时拒绝新任务，不移除尚有效的墓碑。清理使用一次性到期计时器，不轮询保活；全部资源释放后的 Offscreen 关闭与并发创建锁由 S06b 负责。

## 实际验证

完整 pnpm check 通过：类型、lint、格式、生产构建、212 项单元／生产包测试和 20 项 Chromium 测试。

执行器单元验证重复 START、先 CANCEL 后 START、解析期间取消不联网、网络取消与迟到响应、四任务上限、绝对 deadline、过期 deadline、结果 TTL、ACK 后清理、纯保护内容零请求、失败白名单、墓碑表上限及资源释放。Worker 客户端验证消息关联、只发送源文／候选、取消、异常与终止。

真实 Chromium 从生产包创建 WORKERS 用途的 Offscreen，使用单独 Worker 完成一次翻译及固定 12 条样例的原文往返；代码片段没有发送到 HTTP fixture。额外进行一次被取消的挂起请求，14 次本地请求均可计数，重复 START 不增加请求。旁观设置页同时监听 runtime 消息与 Port 消息，未收到 fixture Key；测试结束执行器 active/pendingResults 均为零。只在测试副本授予本地 API 权限，无生产调试接口。

首次真实 Worker 验证发现解析器依赖 decode-named-character-reference 选择了需要 document 的浏览器入口，导致 Worker 启动失败。构建现显式选择该依赖公开默认入口的字符表实现，不需要 DOM；依赖作为构建依赖固定，真实 Worker 样例回归通过。处理器异步化亦先触发既有取消测试超时；在解析返回后、网络发起前重新检查取消信号，回归通过。
