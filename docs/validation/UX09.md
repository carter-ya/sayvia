# UX09 玻璃外观与可移动浮窗

日期：2026-11-03。依据本次会话确认的交互草案实现，工作分支 `codex/glass-appearance`，起点 `2db2092`。

## 最终行为

- 清蓝（crystal）与珊瑚（pearl）为独立配色，每套均支持白天、黑夜、跟随系统。默认清蓝、跟随系统。设置、工具栏、页面浮窗、选择入口及语言菜单共用外观变量；GitHub 原有操作栏入口继续融入宿主的中性色。
- 默认液态玻璃、14% 背景染色浓度及开启阅读保护。深色模式在染色底层之上增强底色，避免白色网页透入后使浅色文字失去对比；该浓度值不等同于整块面板的实际透明度。提供磨砂、半透明、实色，背景染色浓度范围 8% 至 100%；实色使用完整底色并禁用透明度调整。减少透明度／增加对比度的系统偏好下使用实色；不支持 backdrop-filter 时，液态与磨砂也降级为实色。玻璃为网页端的光影近似，不宣称实现原生 iOS 折射。
- 原文折叠区使用 14px 正文、独立实底与清晰边框；可编辑译文也有独立实底。装饰层位于文字后方，背景透明度不作用于文字本身。
- 设置页保存全局偏好；浮窗的材质、不透明度与阅读保护使用单独白名单局部保存。完成保存后同步已打开的工具栏和网页浮窗，不改变草稿、源语言、任务状态或替换资格，不发起额外模型调用。
- 标题栏或移动按钮支持拖动，聚焦移动按钮可用方向键微调。手动位置在滚动时保持，窗口缩小及内容变化后约束在视口内。“恢复浮窗位置”回到当前锚点或默认右上角；重新打开重新定位。收起／展开保留译文。关闭及卸载清理观察器、捕获状态与事件监听。

## 配置与消息边界

原有 v1 存储缺少新增外观字段时按字段补默认值，不清除模型、Key、语言、主题或修订号，不因加载而重写存储。`page.appearance` 只允许已核对的顶层内容脚本修改材质、不透明度及阅读保护，拒绝模型、Key、配色、快速替换和未知字段。连续局部修改按队列合并，保持其他偏好；保存失败回退到已保存外观并允许再次操作，保留译文草稿；后台通知仅包含公开外观字段及修订号，内容脚本拒绝旧修订通知，待保存的外观选择不被旧回复覆盖。

## 验证

新增单元验证覆盖旧配置兼容、凭证与模型修订保留、局部补丁不触发其他默认值、连续局部保存，以及内容脚本来源／字段白名单。新增实际扩展浏览器验证覆盖两套配色与三种主题的保存、系统明暗切换、已打开草稿和工具栏同步、材质及透明度重开持久化、原文实底、拖动、键盘移动、滚动、收起／展开、恢复位置及窄屏。

完整 `pnpm check` 通过：类型、lint、格式、构建、503 项单元测试及 144 项浏览器测试。首轮回归暴露了初始化时提前渲染隐藏面板、语言箭头居中、编辑区间距与短文浮窗高度问题；已在实现中修正，保留原有断言并完整重跑通过。

随后补充保存失败回退／重试和白色网页上的深色文字对比修正。附加修正过程中再次通过类型、lint、格式和 503 项单元；最终构建上通过类型、lint、格式，以及受影响的外观、操作栏定位、语言菜单、阅读预览和紧凑／窄屏共 26 项浏览器测试，新增的保存失败场景包含在这 26 项中。深色模式对主文字和辅助文字按白底及高光的保守合成计算检查至少 4.5:1，并查看两套配色的实际扩展截图。完整浏览器测试集合因此由 144 项增加至 145 项；不将最终 26 项针对性复查表述为完整 145 项重新执行。
