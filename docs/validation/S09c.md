# S09c 右键与快捷键入口

日期：2026-11-01。依赖 S09b（PR #16）。

Chrome 主框架正文选区的右键菜单和阅读快捷键复用同一文档注入、DOM Range 捕获和页面浮窗，打开后直接开始翻译；不使用浏览器传入的 selectionText 降级为纯文本。编辑框菜单和可自定义写作快捷键打开预览，不自动覆盖或提交。阅读默认快捷键为 Ctrl+Shift+Y（macOS 为 Command+Shift+Y），可在 chrome://extensions/shortcuts 修改。

所有入口由 Chrome 的 contextMenus／commands 事件提供目标标签页，不增加网页可调用的任意注入消息。跨 frame 菜单忽略；受限页面失败时给出工具栏徽标和提示，不重试请求。首次注入若原 Range 已不存在，显示重新选择提示，不发送原生菜单的扁平文本。

单元测试覆盖 Chrome 事件路由、主框架限制、不读取 selectionText、精确 documentId、写作只预览、受限页面提示及声明的最小权限。扩展浏览器测试验证实际命令注册、真实后台发送者到内容脚本的直接阅读链路及代码保护。

Headless CDP 的按键输入未触发原生 Chrome 快捷键，不能把它算成快捷键验收。原生验证时 Mac 锁定，无法继续 UI 操作；真实 OS 快捷键与菜单选择仍需在发布前完成，不能以服务路由测试代替。没有改动用户的真实浏览器配置和 API Key。
