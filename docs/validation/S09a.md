# S09a 网站入口基础服务

日期：2026-11-01。直接依赖 S08c（PR #14）。

网站自动入口必须由设置页的真实点击显式启用。Chrome 主机授权与 allowedSites 启用记录分开；API 授权本身不会注入网页。只对实际获授权的明确主机注册持久内容脚本，主框架运行，并向已打开文档注入，不要求重新加载。授权范围遵循 Chrome 的路径／端口语义，不扩展到其他子域名。停用网站入口保留共享 API 主机权限，浏览器撤销权限则清除启用意图。清除全部数据同时移除动态注册。

同文档重复执行 WXT bundle 时复用现有控制器、选区和编辑候选；真正扩展上下文失效和页面退出仍释放资源。自动加载不会绑定或读取编辑框内容，只有显式打开写作入口后才建立编辑会话。页面事件和初始化不会调用模型。

验证新增网站服务单元测试与两项扩展浏览器测试：API 已授权时页面仍无内容脚本；显式启用立即注入并在新文档继续加载；停用后不再自动注入且原 API 翻译仍可用；真实执行 bundle 两次后编辑候选、原文和安全替换仍保持。单元测试另外覆盖撤销后即时重授也不恢复意图、并发偏好保存和注册失败的真实状态。相关 core-workflow 与权限测试合计 18 项通过。完整检查以 PR CI 为准。

这是 S09 基础子层；用户可见的选区图标和自动开始翻译由 S09b 交付，右键与快捷键由 S09c 交付。未宣称完整阅读体验或人工发布验收已完成。
