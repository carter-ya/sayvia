# S09b 选区图标与页面阅读浮窗

日期：2026-11-01。直接依赖 S09a（PR #15）。

明确启用的网站选中正文后显示 Sayvia 图标；点击图标即在页面浮窗开始一次翻译，不需要打开工具栏或再次点击翻译。选区事件、程序模拟点击不会调用模型。浮窗显示当前目标语言和实际模型，提供可展开原文、译文编辑与复制、取消和重新翻译；沿用正式设置的明暗主题及常用语言选项。窄窗口和视口变化后位置保持在可见区域。

模型请求仍使用原 DOM Range 和语义签名：代码不会发送给模型，原网页保持原样；网页脚本切换原生 Selection 不会扩大或换掉已捕获文本，原 DOM 改变则不发请求。纯代码结果在本地返回。编辑框选区不会经阅读浮标发送。关闭、重新打开的焦点按会话更新，未应用修改仍需确认放弃。

inline 请求后台在执行器创建前和实际派发前均检查启用意图与 Chrome 权限；网站停用会取消 inline 任务，后续请求被拒绝。已完成译文仍可复制。复用 S06 的并发、取消、超时与无重试行为。

新增浏览器回归覆盖无需工具栏的直达路径、合成点击、原生 Selection 被脚本切换、DOM 失效、窄视口、停用中断和后台独立拒绝、代码保护与编辑框隔离；调度单元测试覆盖执行器创建期间网站被停用。全部请求使用本机自制模型服务，不能作为真实译文质量验收。

通过实际扩展截图检查明／暗主题、375px 窄窗口和选区图标。浮标与阅读浮窗属于本层交付；右键／快捷键在 S09c，手动弹窗在 S08d。真人语义和真实 GitHub 手动提交验收仍待发布前完成。
