# UX02 GitHub 操作栏与就近浮窗

日期：2026-11-02；基于已合并 UX01 的 `584639c`。

用户截图与代码确认原入口位于 textarea 后、写作浮窗固定右上角。增加带真实工具栏结构的自制 GitHub 页面，原代码在“入口必须在工具栏内”和“浮窗必须靠近触发按钮”两项回归均失败。

修正后，28px 中性色翻译图标位于对应编辑器格式工具栏内，使用 for／aria-controls 关联或同一编辑器容器的唯一工具栏。观察时不读取草稿文本，选择不明确时使用已有手动路径。可信点击绑定该编辑框的选区／全文，不依赖另一个编辑框的焦点，也不调用网站提交。

浮窗通过实时按钮坐标定位，空间不足向上展开，滚动、尺寸及工具栏重建时更新；面板自身高度变化也参与定位。窗口边缘限制位置与可见高度，保留编辑后的候选。关闭或销毁解绑监听与 observer，工具栏变化不重新发起翻译。

本层类型、lint、构建及 6 项编辑器浏览器回归通过，包括经典／现代工具栏、多编辑器和关联不明、延迟重建、只翻译绑定草稿、滚动跟随、上翻、窄屏、关闭与取消。完整检查在提交／CI 中继续执行；合并仍要求最新 head 审核无有效问题与 CI 成功。测试与截图使用隔离自制页面、本地模型，不代表真实 GitHub 人工发帖或真人语义验收。
