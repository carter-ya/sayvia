# S08b 模型设置与连接测试界面

日期：2026-10-31。依赖：已合并 S08a（PR #12）。

## 交付

正式模型设置界面支持多份配置、默认模型、三种服务类型、实际请求地址预览、由明确点击触发的 API 主机授权、Key 留空保留／明确清除，以及已保存配置的连接测试。打开设置时默认选择当前默认模型；新配置与现有配置共用同一保存语义。已保存的 Key 不从存储取回填入表单，保存成功后密码字段清空；保存期间暂停表单编辑，避免响应返回时覆盖刚输入的修改。

连接测试显示未测试、执行中、可用与错误状态，支持取消。表单变动会清除旧结论并取消仍在运行的测试；修改未保存前不能测试。只在真实点击按钮后发起一次固定公开样例，失败不会自动重试。授权结果绑定当次地址，改变地址后旧提示不能覆盖新地址的状态。

切换配置、重新载入或离开含未保存修改的页面时，提供放弃确认；发生跨窗口修订冲突时保留尚未保存的字段，并引导重新载入。设置页采用统一的绿色、浅底卡片、明暗配色和窄窗口布局；弹窗沿用相同基础样式，完整弹窗体验在后续层交付。

## 验证

4 项新增真实扩展浏览器场景覆盖：测试按钮的真实点击、配置保存后方可测试、编辑后旧结论失效、修改候选配置时取消放弃、跨窗口冲突时不丢未保存 Key，以及明确放弃后加载最新配置。显式重新载入使用独立的表单生命周期标识，即使存储 revision 没有变化，也清空未保存 Key、恢复已保存模型并重置测试状态；不能只清除 dirty 标记。使用自制本机服务，没有调用付费模型。原永久 Key、同 ID 更新、API 授权及核心写作流程同步回归。

分别渲染浅色、深色与 375px 窄窗口；检查窄窗口无横向溢出、表单可操作，截图前确认 API Key 输入为空。截图仅使用公开测试配置，不代表真实服务的质量评估。完整类型、lint、格式、构建、单元和浏览器回归结果以本层 PR CI 为准。
