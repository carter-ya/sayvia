# S08c 翻译偏好、权限与本机数据

日期：2026-11-01。依赖：已合并 S08b（PR #13）。

## 交付

设置页提供模型服务、翻译偏好、权限与数据三个入口。偏好支持默认模型、阅读／写作目标语言、常用语言与自定义语言、跟随系统及明暗主题。主题可即时预览，保存后重启仍保留；放弃未保存修改或重新载入会恢复已保存设置。快速替换的开关与实际写作行为在 S10 一起接入，避免提前展示无效果的控制项。

主机授权只在真实点击后调用 Chrome API，显示浏览器实际授予的主机清单并支持逐项撤销。API 与网站可能共享同一主机，界面说明撤销影响。首次新增主机的原生确认框与实际撤销验证见 [原生授权记录](./S08c-native-host-permission.md)。CI 的拒绝路径使用仅测试页的受控拒绝响应，不冒充原生首次同意。

清除全部数据前说明会删除配置、Key、偏好、会话草稿和译文，并取消任务。任务调度锁覆盖配置删除与执行取消，后续任务不能继续用旧 Key；清空 session 并释放空闲执行器，在可通信页面移除面板和恢复点，同时通知其他设置窗口。可以选择同时撤销主机授权；未能全部撤销时明确提示。网站上已经写入的正文不会被清除数据操作改写。

清理中发生修订冲突时不取消原任务；写入失败不会误报“数据仍完整保留”或“全部成功清除”。最终 session 写入失败仍会取消已有执行并释放执行器。来自本窗口的清理广播不会覆盖具体完成／部分失败提示。

## 验证

新增配置清理和调度锁单元测试覆盖永久 Key 删除、修订不可复用、并发任务被取消、后续任务无法取得旧配置，以及失败时的保留和真实错误反馈。

3 项新增扩展浏览器测试覆盖语言／主题重启保留、同版本放弃修改、实际长请求取消、清理后存储不含 Key／草稿、恢复点消失、网站正文不被回滚，以及拒绝授权时无模型请求。清理后重新使用写作入口需重新聚焦编辑框，不复用已经释放的旧映射。

所有模型相关场景使用本机自制服务，未调用付费模型。原生权限验证只使用保留测试域名，未清理或改动现有真实模型配置。完整检查以本层 PR 的 CI 与提交记录为准。真人语义与真实 GitHub 手动提交仍为发布前必过。
