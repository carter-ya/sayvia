地址保留路径前缀，保存时规范化；拒绝远程 HTTP、userinfo、查询、fragment、非法编码及已填完整 chat/completions 的地址。旧的已保存配置仍可读取和修正，不因新校验清除已有 Key。服务预设记录两个已实际调用的型号 gpt-6-luna 与 deepseek-flash；verifiedModels 仅代表当前最小 Chat Completions 请求及固定样例结构验证，不代表 M1／发布质量已通过，也不按模型名称猜测推理参数。

一次请求只发送 model、messages 和 stream:false；segments-v2 发送完整行上下文与有角色的本地保护标记。请求禁止重定向，省略浏览器凭据，不缓存或发送 referrer；固定高优先级翻译指令与源文数据分开。受保护代码／地址不进入模型载荷。拒绝非正常 finish_reason、拒绝回答、工具调用、空／非文本输出及不符合 TranslationPlan 的 JSON；reasoning_content 不作为译文。

字节流读取上限 1 MiB，超限取消；请求、解析和本地重建共用最多 60 秒预算，支持外部取消与调用方更早的截止时间。不自动重试或切换服务。错误只输出预设代码，服务器错误正文和任意异常文本不会进入日志或报告；成功响应若回显当前 Key 也拒绝返回。

真实本地 HTTP fixture 验证 307 不访问目标地址。模拟测试覆盖鉴权、额度、限流、模型不存在、服务错误、无效 UTF-8、缺失 choices、截断、控制输出、超大响应、取消和截止，以及结束后清除计时器。

评估 CLI 通过同一个 translate → 计划 → 请求 → 重建路径运行固定 12 条公开样例。本地服务集成验证实际进程一次 12 个请求、每条完成即追加 JSONL、文件权限 0600、报告无 Key、同路径再次运行在请求前拒绝覆盖。模拟报告始终保持人工评审 pending，m1Passed:false。

## 本机运行真实评估

以下命令适用于 zsh，分别运行同组 12 条样例。Key 通过不回显的本机输入设置，不要发送到聊天或放入命令参数。

```sh
mkdir -p evaluation-results
read -rs "SAYVIA_API_KEY?OpenAI API Key: "
export SAYVIA_API_KEY
pnpm evaluate --provider openai --model gpt-6-luna --out evaluation-results/openai-first.jsonl
unset SAYVIA_API_KEY

read -rs "SAYVIA_API_KEY?DeepSeek API Key: "
export SAYVIA_API_KEY
pnpm evaluate --provider deepseek --model deepseek-flash --out evaluation-results/deepseek-first.jsonl
unset SAYVIA_API_KEY
```

每次会产生最多 12 次真实请求及相应费用，不自动补跑失败样例。自定义服务使用 --provider openai-compatible --base-url 加准确 Base URL；模型名称同样由用户指定。输出父目录须已存在，文件必须为新文件。

默认地址来自服务预设；真实执行在 Node 本机工具中进行，不能据此视为扩展 host 权限、Offscreen 生命周期或后台恢复已验证。浏览器设置中的永久 Key 保存行为保持 S02，不由临时评估环境变量替代。

报告含版本、公开源文、译文、耗时、格式／保护结果、错误码和人工参考，不含 Key、完整 API 响应或私有 URL。逐条完成后即保存，中断后保留已完成的记录，不自动续跑；再次全组评估使用新输出文件，仍会产生新的请求。原始本机报告目录被 Git 忽略，人工审核后再将公开验收结论整理进 docs/validation。
