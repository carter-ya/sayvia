# S08a 设置服务与连接测试

日期：2026-10-31。依赖：已合并 S07 及其持续验收修复。

## 范围

新增偏好保存的受限设置命令，支持默认模型、阅读／写作语言、主题和快速替换偏好。使用原有仓库修订控制、写入队列和凭证投影，不重写或暴露已有 Key，也不改动模型配置自身的 revision；错误 ID 或过期全局 revision 不覆盖现有配置。

新增仅设置页可调用的连接测试命令；模型和地址均来自已保存配置，不接受 UI 临时 Key、URL、用户草稿或目标标签页 ID。实际标签页来自浏览器 sender。测试只发送公开固定文本 `Hello from Sayvia.`，调用原有 Chat Completions 路径验证权限、鉴权、模型、响应格式及最小文本生成，不声称验证翻译质量。正式按钮与状态由 S08b 接入，不在此层新增第二套用户流程。

测试复用任务调度与 Offscreen／Worker，包括全局并发、60 秒截止、取消、按 clientTaskId 去重以及取消先于开始的墓碑记录。绑定 providerId 与 providerRevision；任务捕获凭证前再次核对版本，读取结论时复查当前版本，配置改变后旧结论无效。返回值只有绑定信息、状态及安全错误码，不返回模型文本或 Key。关闭设置标签页沿用现有标签页清理流程。

## 验证

类型检查、构建与 285 项单元／生产包测试通过；新增 2 项真实扩展浏览器测试通过。覆盖偏好重启后保留、Key 不进入 DTO、默认模型切换、并发修订冲突、固定样例、真实 sender 权限、重复测试只有一次请求、配置变化后失效，以及取消先于开始时零请求。浏览器 API 使用本机公开测试服务，未调用付费模型。完整回归以本层 PR 的 CI 与提交记录为准。
