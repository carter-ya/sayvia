# S04a 网页选区与输入契约验证

- 日期：2026-10-30
- 基线：S03 已合并，main 2f13748
- 范围：三类 SourceInput 契约、DOM 可见选区、语义区间和内存快照
- 环境：macOS arm64，Node 22.23.2，pnpm 10.21.0，Playwright Chromium 156.0.8078.4

## 验证结果

完整 pnpm check 通过类型、静态检查、格式、生产构建、58 项单元／生产包测试和 13 项浏览器测试。本层新增 25 项单元测试及 4 项 Chromium 测试。

DOM 与真实浏览器 fixture 覆盖代码内的局部选区、嵌套代码、pre 缩进、跨链接标签、跨段落、元素边界、显式换行、emoji 偏移、HTML 缩进空白和保留空白样式。只提取可见选区，排除隐藏内容、脚本、模板、表单值和插件 UI；不读取链接隐藏目的地，不改变原 DOM 或加载资源。

浏览器测试先发现 HTML 缩进产生多余空格，导致保护偏移随之错误；修复为延迟写入普通空白、丢弃块边界缩进，并在输出每段时同步建立区间后通过回归。code／pre 与保留空白样式内容不做末尾 trim。

输入校验覆盖 Unicode code point 12,000 字符上限、UTF-16 边界、非法代理项、保护区间重叠及越界、未知字段、空源文和片段数限制。提取另限制遍历节点与深度，超限拒绝，不能截断后继续翻译。

选区快照只保存在内容脚本内存。焦点变化导致实时选区折叠时，已捕获内容仍可读；原节点移除、文字／代码语义变化和地址变化后拒绝使用。失败捕获清除之前的快照，调用者不能修改内部缓存。

## 验证边界

生产内容脚本仍为待授权的动态入口，没有默认网站注入或新增权限。当前只在可信右键事件捕获快照，尚未接通翻译消息、快捷键或面板。首次注入没有有效 Range 时需要重选；Shadow DOM 与多 Range 选区明确拒绝，不能以纯文本静默回退。

Markdown 解析、纯文本保护、TranslationPlan 与 12 条质量样例属于 S04b，模型协议与真实模型质量验证属于 S05。测试用句柄只在 tests/fixtures 中，不进入生产包。本层不宣称完成真实模型验证或 M1。

## PR review 回归修复

两项 P2 意见均已在修改提取器前复现：5 项 DOM 单元测试与 2 项 Chromium 测试失败。

- 关闭的 details：只允许第一个直接 summary 的可见内容进入源串，排除隐藏正文、直接文本、额外 summary 及被外层折叠隐藏的嵌套 disclosure。打开后正文仍可正常选择。可见性缓存不把“details 自身可见”错误传播给其隐藏子节点。
- 实际布局边界：由计算后的 display 判断块、列表项、表格与 flex/grid 边界，替代标签名白名单。原生 dt/dd、block 样式 span 会分隔；inline 样式 div 不再插入伪换行。

修复后完整 pnpm check 通过类型、静态、格式、生产构建、63 项单元／生产包测试及 15 项浏览器测试。没有真实网站提交或模型请求；后续按新 head 重新请求 Codex 审核。

后续审核另确认 3 项 DOM 与 1 项 Chromium 失败：content-visibility:hidden 的后代仍被提取，NBSP／全角空格被 trim 当作普通缩进丢弃。现在沿祖先排除明确隐藏的 content-visibility 子树，空白折叠只匹配 CSS 可折叠的 ASCII 空白，不改写 NBSP／全角空格或其后的代码偏移。

又一轮复审先复现 5 项 DOM 与 2 项 Chromium 失败：跨 Shadow 宿主时读取到未渲染的 light DOM，pre-line 在文本节点间产生双空格并保留换行两侧多余空格。现在遇到 Shadow 宿主即拒绝该选区，使用 Chrome 的 openOrClosedShadowRoot 检测关闭根；扩展上下文缺少检测能力时失败关闭。pre-line 复用跨节点普通空白折叠并单独保留换行。Chrome 原生关闭根检测已在真实扩展页验证，不增加 manifest 权限。完整检查通过 71 项单元／生产包测试及 18 项 Chromium 测试。[Chrome DOM API](https://developer.chrome.com/docs/extensions/reference/api/dom)
