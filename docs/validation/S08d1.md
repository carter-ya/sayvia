# S08d1 手动翻译会话服务

日期：2026-11-01。直接依赖 S09c。

手动草稿按浏览器标签页隔离，原文、候选、目标语言与所选模型仅进入 TRUSTED_CONTEXTS 的 storage.session，不进入永久存储或网页。消息仅允许可信 popup 上下文，仍通过浏览器验证目标标签页；不接受 Key、URL 或跨模式参数。

输入修改立即发送保存请求，使用弹窗编辑会话、递增序列与基准修订处理乱序，拒绝旧窗口覆盖新窗口。开始翻译时核对已保存草稿修订，运行中的手动请求拒绝草稿覆盖；结果和任务沿用既有执行器与每标签页互斥，关闭弹窗不取消请求也不重发。正常后台重启保留会话代际，清除全部数据会旋转代际，使尚未处理的旧窗口保存不能重新写回私有草稿。保存失败保留前一份内存状态。

弹窗初始化在调度锁内一次读取配置、草稿和会话代际，避免清理过程中拼接旧草稿与新代际。公开视图不返回内部编辑租约；API Key 仍只在后台与执行器使用。

单元验证覆盖乱序修改、竞争窗口、清理后的迟到保存、失败回滚和不可信上下文。完整手动输入、关闭重开、后台完成、取消及清理的界面回归由直接后继 S08d2 提供。该子层不宣称正式弹窗已经发布。
