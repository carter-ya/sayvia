# S06b 后台任务代理与恢复

日期：2026-10-31；基于已合并的 S06a（PR #8）。

## 已实现

后台从真实 sender 取得网页 tabId、主 frame 与 documentId，拒绝调用方提供目标标签页，区分网页与受信任 popup 的手动任务。消息使用版本、requestId、严格字段白名单和 SourceInput 校验；网页不能传入地址、Key 或内部执行参数。主机权限通过已保存配置的地址检查，只声明 HTTPS 与本机 HTTP 的可选权限，没有默认主机授权或网站注入。主机匹配不作为精确端口／路径边界，实际请求仍沿用保存的完整 Base URL。

每个真实标签页一个活动任务，网页和该页关联的手动任务共用互斥；全局最多四个活动任务，没有付费队列。先保存无正文路由再派发；同一 clientTaskId 在其文档／nonce 范围内去重，取消墓碑覆盖尚未到达的 START。路由与墓碑各最多 256 条、短期保留五分钟，页面源文／译文／Key 不进入 session。popup 的手动输入与结果单独保留在受限 session，关闭 popup 不删除，目标标签页关闭／导航时删除。

Offscreen 创建、派发、查询和空闲关闭共用串行生命周期锁。开始确认丢失后只查询，不重发 START；恢复也不创建新执行器。后台重启后从 session 路由重新绑定现有执行器，沿用原 epoch/token，结果按原 documentId 与 nonce 投递，不能恢复快速应用资格。页面须确认收到才清除执行器结果；手动结果先存入 session 再确认。

取消、关页／导航、权限撤销和配置删除中止相应活动请求。执行器丢失返回 interrupted/CONTEXT_LOST，迟到完成不能覆盖取消终态；失败和超时有定向状态事件。全部活动任务与待交付结果释放后关闭 Offscreen，没有保活轮询。

## 实际浏览器证据

使用真实 Chromium、构建后的生产后台／Offscreen／Worker 和本地 HTTP fixture；仅临时测试副本授予本机主机权限并安装测试内容脚本，未加入生产调试入口，没有付费模型请求。

- 快速真实请求、按原文档交付、重复 START 零新增请求、取消网络与空闲关闭。
- 35 秒后才返回响应头：请求发出后通过 CDP 终止后台，再分离调试连接，期间不轮询后台；结果成功返回原网页，canApply=false，HTTP 计数仍为 1。
- 永不响应的 API：真实约 60 秒收到 timedOut/TIMEOUT，连接中止，HTTP 计数仍为 1，Offscreen 关闭。
- popup 与网页争用同一页得到 TASK_BUSY；关闭并重新打开 popup 后可读取手动输入及结果。
- 缺少 localhost 主机权限时，在创建执行环境或请求前拒绝；已授权 127.0.0.1 不授权 localhost。
- 配置删除、目标标签页关闭／导航均中止网络；执行器直接丢失时只中断任务，不重放。
- 内容脚本读取 session 被 Chrome 拒绝，页面任务路由索引不含源文、译文或 Key。

来源字段以实际 Chrome 验证为准：Offscreen 的 Port sender 有 id、url、origin，却没有 documentId；后台验证浏览器提供的精确扩展来源及唯一 Offscreen 上下文，仅在 sender 提供 documentId 时额外比对。网页 sender 则必须提供真实 documentId。popup 以独立扩展标签页打开时有 sender.tab，仍按其精确扩展地址认定受信任 UI，不能把它当普通网页。
