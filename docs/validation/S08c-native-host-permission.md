# S08c 原生主机授权验证

日期：2026-11-01。浏览器：Google Chrome for Testing 156.0.8078.4（实际窗口提示栏）。使用已打开的 Sayvia 设置页，只操作无真实内容的保留测试域名，不改动已保存模型、Key 或原有 API 主机授权。

1. 在“权限与数据”输入 `https://docs.example.test`，点击“授权此网站”。
2. Chrome 原生确认框显示“Sayvia 请求获得更多权限”，内容仅为“读取和更改您在 docs.example.test 上的数据”，提供“拒绝”和“允许”。
3. 点击允许，设置页显示 `docs.example.test 已获授权。`，授权清单新增 `https://docs.example.test/*`；原有 API 授权仍在。
4. 点击该测试域名对应的撤销按钮，清单移除该项，并显示“已撤销授权，相关进行中任务将取消。”
5. 清空临时测试地址。没有点击清除数据，没有读取或更改 Key，也没有发起模型请求。

这是实际原生确认框与浏览器权限状态的验证，不是注入 grant 返回值。CI 中的拒绝路径使用仅存在于测试页的受控响应；不把它冒充原生首次授权。现有真实翻译窗口及其配置保持不变。
