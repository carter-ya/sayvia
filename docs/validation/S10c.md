# S10c 单次源语言选择

日期：2026-11-01，直接依赖 S10b。补齐 PRD 6.1“默认自动识别，也允许手动指定”。

阅读与写作面板、工具栏手动翻译均增加源语言选择，默认自动识别，提供现有语言列表及自定义名称。页面面板的新任务默认自动识别，单次可改；改动后清除旧候选与替换资格，并要求重新点击翻译，不因选择语言自动收费。阅读图标的首次直达仍自动开始；需要在首次请求前指定语言时可用工具栏备用入口。目标语言与永久阅读／写作偏好不受影响。

手动页保存单次源语言至已有会话草稿；关闭立即重开、请求启动及后续修改均保留所选值。旧草稿缺少字段时界面回退为自动识别，旧保存消息仍接受，存储版本及永久 Key 配置不变。用户临时输入空的自定义语言时可保存草稿，但翻译按钮不可用。
