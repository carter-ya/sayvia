# S03 编辑框安全验证记录

- 日期：2026-10-30
- 基线：S02 1bd918b
- 范围：编辑框身份、草稿修订、选区写入、一步恢复与生命周期
- 环境：macOS arm64，Node 22.23.2，pnpm 10.21.0，Playwright Chromium 156.0.8078.4

## 已执行检查

类型、静态检查、生产构建通过。累计 27 项单元／生产包测试和 6 项浏览器测试通过，其中 S03 新增 15 项 DOM 单元测试与 4 项浏览器测试。

验证内容包括源选区绑定、焦点切换、输入后撤回、无事件脚本赋值、伪造快照、移除后插回、恢复冲突、连续写入的一步恢复、IME、框架回滚、竞争输入、并发写入、长度与只读限制、密码字段类型变化，以及注册表释放。每个文档共用一个 MutationObserver，无定时轮询。

本地 Chromium 页面使用真实 React 受控 textarea。测试在替换与恢复后，通过测试者点击本地模拟提交按钮，确认 React 保存的实际正文分别与译文及原文一致；扩展写入本身没有触发提交。测试不向外部网站发表评论。

浏览器另验证隐藏编辑器、节点移除及 SPA pushState 离开再返回都会使旧快照失效。导航监听按可用性使用 Navigation API，并保留文档身份、地址、pagehide、popstate 和 hashchange 检查。[Navigation API 参考](https://developer.mozilla.org/en-US/docs/Web/API/Navigation/navigate_event)

## 验证边界

GitHub 的 Issue／PR 常规评论框识别规则有 DOM 单元测试，尚未完成登录实站的人工提交验收；Discussions 与未知 GitHub 编辑器保留复制回退边界。此层不能据此声称 GitHub 的全部编辑器都已通过兼容验证。

测试专用编辑器操作句柄只存在于 tests/fixtures，本地 Vite 服务只在测试时运行；生产包不包含测试控制句柄或任意回写消息接口。内容入口仍等待后续按网站授权与动态注入，普通安装不会自动运行到网站。

翻译格式校验由 S04 提供，并在 S07 与安全写入连接。当前不提供最终翻译 UI，未完成 M1。
