## 已执行检查

类型、静态检查、构建通过。12 项生产包／仓库测试和 2 项浏览器测试通过。

仓库测试覆盖访问限制先于读写、Key 不进入脱敏响应、配置仓库重建、空 Key 更新保留、显式清除与删除、并发修订冲突、未知结构保留、存储写入失败回退，以及明确的扁平原型格式迁移。原型格式不是已发布版本，不代表完成了真实用户旧版本的数据升级。

浏览器测试使用生成的临时配置文件和虚假 Key：
1. 设置页保存后 Key 输入框清空，响应不包含 Key 或 secretRef。
2. 关闭并重新启动浏览器，配置与 hasApiKey 状态保留。
3. 在同一路径将临时扩展版本从 0.1.0 改为 0.1.1，扩展 ID 与配置保留。
4. 测试专用内容脚本读取 storage.local 被拒绝。
5. 删除配置后，实际本地 secrets 对象为空。

存储隔离测试只在临时复制的扩展包中增加 localhost 内容脚本探针；生产包不包含探针或默认网站权限。测试不使用个人浏览器配置、不调用模型。

当前只有最小设置页，尚无连接测试、完整权限管理和翻译功能。删除活动模型时取消模型任务的行为将在引入任务代理时接入。物理设备重启没有执行，浏览器重启和正常版本更新已经实际验证；本机永久存储未设置时间过期。
